💬 Вбудовані субтитри Zoom (необов’язково)

Як отримати URL (1 раз на кожну зустріч):
  1. На сайті zoom.us → Settings → Meeting → In Meeting (Advanced) → увімкніть Closed captioning і «Allow use of caption API Token to integrate with 3rd-party Closed Captioning services».
  2. Під час зустрічі/вебінару організатор натискає Captions / CC (Субтитри) → Set up manual captioner (або «Third-party captioning service») → Copy the API token.
  3. Вставте скопійоване сюди і натисніть «Перевірити».
Назви меню можуть трохи відрізнятися залежно від версії Zoom. Якщо цієї опції немає у вашому акаунті — нічого страшного, посилання для глядачів працює завжди.

🗂 Сесія та записи

Усі субтитри автоматично зберігаються в папку transcripts (українською, англійською, двомовний текст і .srt).

Щоб вимкнути програму, можна також просто закрити чорне вікно.

👋 Крок 1. Ключ перекладача Gemini

Переклад робить Google Gemini — це безкоштовно. Потрібен ключ (1 хвилина):

  1. Відкрийте aistudio.google.com/apikey і увійдіть у свій Google-акаунт.
  2. Натисніть «Create API key», скопіюйте ключ і вставте нижче.

Без ключа програма теж працює (резервний перекладач), але якість перекладу нижча.

🔊 Крок 2. Звідки брати звук

Оберіть пристрій, через який ви чуєте Zoom. Зазвичай підходить перший варіант.

Увімкніть будь-яке відео з англійською мовою — смужка має рухатися. Програма захоплює те, що грає цей пристрій.

🧪 Крок 3. Тест

Натисніть кнопку — програма «прослухає» короткий англійський запис і покаже український переклад.

✅ Готово!

Перед лекцією:

  1. Натисніть велику зелену кнопку СТАРТ.
  2. Скопіюйте повідомлення для чату і вставте в чат Zoom.
  3. (Необов’язково) підключіть вбудовані субтитри Zoom — інструкція в панелі.
